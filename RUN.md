# Run

1. Install Node.js 20+
2. Run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

MangaDex is live through the Express proxy.
The Comics tab is intentionally disabled because no authorised Batcave API/feed is configured.

To diagnose MangaDex, open `/api/mangadex/health` while the server is running.
