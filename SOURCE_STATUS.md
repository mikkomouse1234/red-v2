# Source status

## MangaDex

The MangaDex section is live. Search, manga details, English chapter feeds, At-Home page resolution, and MangaDex image proxying all use live API responses. There are no local MangaDex catalogue/chapter/page fallbacks.

## Comics

The previous project contained fabricated Batcave catalogue entries and generated page URLs. Those have been removed so the app no longer presents fake comic content as if it came from Batcave.

A real Batcave integration is not included here. Add an authorized API/feed or a source you have permission to access before enabling the Comics section.
